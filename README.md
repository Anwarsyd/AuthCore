# AuthCore

A secure REST API authentication system built with Django REST Framework and JWT.

## Features

- Custom user model with email authentication
- User registration
- Password validation
- JWT authentication
- Access and refresh tokens
- Refresh token rotation
- Refresh token blacklisting
- Email verification
- Login restriction for unverified users
- Profile retrieval and update
- Change password
- Forgot password
- Password reset
- JWT token invalidation after password change
- Automated API testing with pytest

## Tech Stack

- Python
- Django
- Django REST Framework
- SimpleJWT
- SQLite
- Pytest
- Postman
- Git & GitHub
